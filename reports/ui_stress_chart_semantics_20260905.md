# Семантика графика стресс-теста — 2026-09-05

График цифрового двойника разделён по источнику данных:

- синяя линия «Наблюдаемый NDVI» — доступные исходные измерения;
- оранжевая точечная линия «Восстановленный NDVI» — значения в синтетических пропусках, полученные из конкурсного prediction artifact;
- красная пунктирная линия «NDVI по сценарию» — контрфактическая оценка при изменённой погоде, не submission;
- зелёная точечная линия — сезонная норма.

Для наблюдений и восстановления включены маркеры, `connectgaps=False` и линейные сегменты. Это убирает ложные вертикальные соединения через длинные пропуски и не создаёт искусственных сглаженных всплесков. В подсказке под легендой явно указано, где находятся конкурсные предсказания.

Проверки: AppTest без исключений, визуальный просмотр Streamlit после hot-reload. Prediction CSV не изменялся.
