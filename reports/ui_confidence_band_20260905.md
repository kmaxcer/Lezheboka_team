# UI confidence band — 2026-09-05

Добавлен переключатель «Показывать коридор доверия» на графике NDVI.
Коридор строится вокруг AOI climatology и использует доступное
`ndvi_climatology_std`, ограниченное физически разумным диапазоном 0.03–0.25.
Он не меняет predictions и не участвует в конкурсном CSV; это визуальная
оценка неопределённости для жюри и пользователя.

Проверка: `py_compile` и `pytest -q` → 15 passed; Streamlit AppTest без
исключений. Upload/push не выполнялись.
