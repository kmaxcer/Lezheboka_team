## Приоритетные правки

### P0 — перед показом жюри

1. Исправить битую ссылку в README на отсутствующий metadata-файл. Оставить один
   канонический кандидат, его SHA, формулу и ссылку на существующий manifest.
2. Выполнить обязательный перевод всех комментариев и inline-комментариев в
   `app.py`, `src/`, `scripts/`, `tests/` на русский. Английские docstring можно
   также локализовать для единообразия отчёта.
3. Добавить в README короткий демонстрационный сценарий цифрового двойника и
   радара риска с ожидаемыми полями (`risk_score`, `top_factors`, `ΔNDVI`), чтобы
   дополнительные 5 баллов были проверяемыми, а не только заявленными.

### P1 — если есть время

1. Сохранение пользовательских полигонов в новый timestamped JSON через кнопку
   «Экспорт», импорт этого файла при старте; существующие файлы не перезаписывать.
2. Добавить `tests/test_app_smoke.py` на `streamlit.testing.v1.AppTest` (загрузка,
   4 метрики, переключение «Сетка AOI», цифровой двойник, отсутствие исключений).
3. Добавить retry/backoff и offline mock в `src/external_data.py` и
   `prepare_region_context.py`; при частичной недоступности источника сохранять
   пустой artefact + manifest с ошибкой вместо падения всего запуска.
4. Удалить дублирование `_geojson_centroid` в `app.py`, использовать единую
   реализацию из `src/external_data.py`, чтобы проверки геометрии и UI не
   расходились.
5. Создать `research/INDEX.md` со ссылками на baseline, победителя, отрицательные
   kernel/SVR probes и критерии остановки. Это сократит время ревью и повысит
   воспроизводимость исследований.
