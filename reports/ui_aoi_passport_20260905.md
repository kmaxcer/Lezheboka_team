# AOI passport — 2026-09-05

Добавлен воспроизводимый экспорт автономного HTML-паспорта для выбранного полигона. Паспорт строится из текущего обогащённого среза и не меняет prediction CSV.

Содержимое: период анализа, покрытие климатологической нормы, число наблюдений/восстановлений/пропусков, аномалии и critical, число и максимальная длительность стресс-периодов, радар риска 0–100 с факторами, SVG-спарклайн NDVI и стандартный стресс-тест (+2 °C, −30% осадков, severity 1.0) с медианным ΔNDVI и оценёнными чувствительностями.

Формула риска: 0.35·z + 0.25·critical + 0.15·suppression + 0.15·persistence + 0.10·uncertainty, нормированная на 0–100. Чувствительности цифрового двойника являются интерпретационными сценарными оценками.

Экспорт доступен кнопкой «Скачать паспорт AOI» в разделе «Паспорт полигона»; имя содержит AOI и UTC timestamp. HTML автономен, внешние сервисы не требуются.

Проверки: `python -m py_compile app.py`; `pytest -q` → 15 passed. Визуально проверены заголовок, метрики, легенда, таблицы и доступность кнопки в Streamlit на `http://localhost:8511/`.

Дополнительная smoke-проверка: `streamlit.testing.v1.AppTest.from_file("app.py").run(timeout=90)` завершилась без исключений (0 exception); в дереве UI найдены 2 selectbox и 2 download-кнопки, включая паспорт AOI. Выгрузка submission и сетевые действия не выполнялись.

После smoke-проверки нормализован вывод `n_days` в HTML-таблице: пустые/нечисловые длительности теперь безопасно отображаются как 0, исключая падение экспорта на неполных периодах. Повторно: `py_compile` успешно, `pytest` → 15 passed, AppTest → 0 exceptions.
