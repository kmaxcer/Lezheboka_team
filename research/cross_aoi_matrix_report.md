# Cross-AOI collaborative completion

Проверена leakage-safe схема для пропусков private-подобного holdout: из private удалены целевые строки holdout, затем к train добавлены только оставшиеся видимые private targets. Для каждой даты вычислялось среднее `primary_ndvi` по другим AOI; дополнительно проверены окна ±3, ±7, ±15 и ±30 дней. Полученное значение смешивалось с текущим `ext40`.

На holdout `private_cohort_blend_holdout_predictions.csv` (2644 строки) same-date peer сам по себе слабый: RMSE 0.1834. Малый фиксированный blend дал:

| peer weight | RMSE |
|---:|---:|
| 0 (ext40) | 0.069864 |
| 0.02 | 0.069776 |
| 0.05 | 0.070366 |
| 0.10 | 0.072119 |

Соседние временные окна ухудшили результат даже при весе 0.02 (около 0.0701). Выигрыш 0.00009 RMSE нестабилен и значительно меньше устойчивого history-only peer blend; в production не включён. Рекомендуется сохранить эксперимент как диагностический и использовать только после подтверждения на дополнительных масках.
