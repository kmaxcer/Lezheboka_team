## Минимальный пакет сдачи

- репозиторий с `src/infer.py`, `src/anomaly.py`, `src/validate.py`;
- `README.md`, `requirements.txt`, команда batch-инференса;
- `submission.csv` только с колонками `anon_polygon_id,date,primary_ndvi_pred` и только для `is_synthetic_gap=True`;
- описание источников, лицензий, ограничений и seed/параметров;
- скриншот или live-demo: выбор AOI → ряд NDVI → восстановленные точки → период/статус аномалии.

## Воспроизводимость

Проверяющий должен запустить из корня проекта:

```powershell
python -m pip install -r requirements.txt
python src/infer.py --private private_features.csv --train train_dataset.csv --output submission.csv --bin-days 30
python src/anomaly.py private_features.csv --predictions submission.csv --output enriched.csv --periods periods.csv
python -m pytest -q
```

В README необходимо явно указать, что исходные CSV не коммитятся и передаются путями через CLI. Нельзя менять исходные файлы или дописывать строки после stop-code.

## Сценарий 3-минутной защиты

1. 20 с: проблема облачных/нерегулярных наблюдений и риск ложной аномалии.
2. 40 с: train/private, 78 AOI, скрытые контрольные даты, метрика RMSE.
3. 60 с: ближайшие наблюдаемые `primary_ndvi`, source calibration S2→Landsat→MODIS, fallback.
4. 40 с: baseline против улучшенного метода на псевдо-CV; отдельно edge/длинные gaps.
5. 40 с: UI/график с оригинальными и восстановленными точками, z-score (`normal/suppression/critical`).
6. 20 с: ограничения и следующий шаг (внешние спутниковые/метеоданные, HANTS/Kalman для длинных разрывов).
