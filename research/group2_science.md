# Group 2 — научные методы для «Агропульса»

## Что следует из литературы

1. **Локальная интерполяция / SG.** Savitzky–Golay сохраняет форму фенологического пика лучше простого moving average, но требует аккуратного окна и плохо работает на краях и длинных разрывах ([Chen et al., 2004](https://doi.org/10.1016/j.rse.2004.03.014)). Для наших данных контрольные пропуски в основном одиночные/двойные, поэтому линейная интерполяция по ближайшим *наблюдаемым primary_ndvi* — обязательный baseline. Интерполировать по соседнему календарному дню нельзя: рядом бывают естественные пропуски.

2. **HANTS / Fourier.** Гармоническая регрессия хорошо использует годовую сезонность и одновременно отбрасывает выбросы; рекомендуемые глобальные параметры HANTS: NF=4, FET=0.05, DoD=5, Delta=0.5 ([Zhou et al., 2021](https://doi.org/10.3390/rs13214251)). Ограничение: при резких фазовых переходах и индивидуальном сдвиге сезона сглаживает пики; HANTS лучше использовать как fallback/ensemble для длинных разрывов, не как единственный предиктор.

3. **Whittaker / multi-sensor.** Whittaker smoothing с penalty на вторую разность устойчив к шуму; комбинация MODIS + Landsat + Sentinel повышает плотность серии ([Zhang et al., 2023](https://doi.org/10.3390/ijgi12060214)). В нашем private на контрольной строке все динамические поля замаскированы, поэтому прямое fusion на этой строке невозможно; использовать только соседние валидные `primary_ndvi` и сенсорные ряды для калибровки.

4. **State-space / Kalman.** Динамическая линейная модель с Kalman filter/smoother даёт ретроспективное заполнение и интервалы неопределённости, моделируя тренд+сезонность+ошибку; multi-sensor версия масштабируется через локальные окна ([Wikle et al., 2021](https://doi.org/10.1093/jrsssc/qkaa026)). Практично для блоков длиной 3+ и краёв серии. Для одиночных gaps выигрыш над локальной линейной моделью, вероятно, мал.

5. **Gaussian process.** GPR естественно даёт среднее и дисперсию прогноза; полезен для оценки доверия аномалии, но дорог при 100k строк и требует ядра с периодичностью/длиной сезона. Использовать только как исследовательский малый baseline на отдельных AOI, не в основном пайплайне.

6. **Deep learning.** CNN–RNN/LSTM, особенно с SAR или несколькими сенсорами, превосходят линейные методы на плотных фиксированных сетках, но нуждаются в большом числе обучаемых полных последовательностей и неустойчивы при domain shift ([Tsardanidis et al., 2024](https://doi.org/10.1016/j.compag.2024.109732); hybrid KF–LSTM, 2025: [Sensors](https://doi.org/10.3390/s25175299)). В нашем private скрытая строка не содержит S2/Landsat/MODIS/ERA5 признаков, поэтому DL может использовать только ID, дату и контекст соседей; это слабее и рискованнее, чем calibrated interpolation.

## Рекомендованный порядок экспериментов

1. **B0:** ближайшие валидные точки слева/справа по AOI+год, линейно по фактическому числу дней; fallback — ближайшие по AOI за другие годы.
2. **B1:** B0 + sensor-bias correction (S2/Landsat/MODIS), оценённая на train там, где одновременно доступны источник и primary.
3. **B2:** B0 для gaps длиной ≤2; для длинных/краевых gaps — HANTS NF=4 или Kalman smoother; смешивать по длине разрыва.
4. **B3:** seasonal harmonic/Whittaker ensemble с весом, обратно пропорциональным CV-ошибке на псевдо-masks.
5. ML/DL запускать только после строгого time-block CV; случайный row-CV завышает качество.

## Ошибки и защита

- Не заполнять natural blanks и не использовать masked row features.
- Ключ submission: только `is_synthetic_gap=True`, ровно один прогноз на `(anon_polygon_id,date)`.
- До расчётов фильтровать экстремальные sensor values; в train встречаются явно физически невозможные EVI/NDWI и один `primary_ndvi≈−2.13`.
- Клип финальный NDVI в диапазон, выученный по train (с разумным расширением), и отдельно логировать edge cases/uncertainty.

## Вывод

Для этой задачи научно обоснованный и быстрый путь — robust local interpolation + source calibration, с HANTS/Kalman fallback для редких длинных пропусков. Сложные DL/GPR оправданы как абляции и демонстрация, но не как первый production-кандидат.
