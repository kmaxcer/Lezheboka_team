# Агропульс: параллельный конвейер

Ограничение: одновременно доступны 4 слота, поэтому группы ротируются; внутри каждой группы роли выполняются одним агентом последовательно.

| Группа | Роли (3–4) | Статус | Артефакты |
|---|---|---|---|
| G1 Данные/ошибки | схема и пропуски; выбросы/источники; проверка baseline; CV-рекомендации | готово | `group1_data.md` |
| G2 Научные методы | интерполяция/сглаживание; state-space/GP; ML/deep TS; shortlist | готово | `group2_science.md` |
| G3 ML/временные ряды | pseudo-CV; source-aware модели; ансамбль; error analysis | готово | `group3_ml.md` |
| G4 Инженерия/UI | CLI; anomaly API; web demo; тесты/запуск | готово | `group4_engineering.md` |
| G5 Упаковка | README/repro; презентация; критерии; финальный чек | готово | `group5_packaging.md` |

Исходные файлы не изменяются; Downloads не используется для записи.

## Error-sprint (завершён)

Координатор дополнительно ротировал три роли: taxonomy, fallback experiments,
inference audit. Добавлен `src/error_analysis.py`; в `src/infer.py` исправлены
глобальная sensor-калибровка (сезонные 30-дневные DOY-карты) и prior по общей
дате/году съёмки. Полный private-like CV улучшился примерно с `0.0786` до
`0.0706` RMSE.
