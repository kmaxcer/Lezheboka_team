# Быстрый спринт: edge/long-gap fallback

## Цель

Проверить, чем закрывать контрольные точки без опоры слева/справа или длинные пропуски, не добавляя тяжёлые зависимости. Основной source-aware локальный прогноз оставлен без изменений.

## Наблюдения

- Псевдо-CV на масках private (2019–2024, 1114 точек) даёт RMSE `0.0786` для текущего source-aware интерполятора против `0.0994` у nearest-linear.
- По годам source-aware: 2019 `0.0725`, 2020 `0.0685`, 2021 `0.1008`, 2022 `0.0763`, 2023 `0.0820`, 2024 `0.0708`.
- Контрольные даты преимущественно одиночные: около 85% — длина 1, около 6% — длина 2; длинные блоки редки. Поэтому сложная сезонная модель не должна заменять локальную опору.

## Сравнённые fallback-гипотезы

1. AOI/year локальная линейная регрессия по ближайшим наблюдениям, с affine-калибровкой источников — production-путь.
2. Гармоника `sin/cos(DOY)` по истории AOI — только крайний fallback.
3. Робастная сезонная медиана по `crop_type + DOY` — fallback при отсутствии истории AOI.
4. Whittaker/Savitzky–Golay/Kalman — не включены: в окружении нет scipy/statsmodels, а при одиночных дырах ожидаемого выигрыша нет.

## Решение и исправление

Чистую сезонную реконструкцию не используем: на искусственных масках она
давала примерно `0.18–0.20 RMSE`. Вместо этого в `src/infer.py` добавлена
сезонная affine-калибровка sensor-bias: отдельные карты S2/Landsat/MODIS по
30-дневным DOY-бинам с глобальным fallback. Это не меняет основной локальный
предиктор, но исправляет сезонный сдвиг источников.

На трёх масках train RMSE улучшился:

| маска | до патча | после патча |
|---|---:|---:|
| random15 | ~0.0731 | ~0.0714 |
| private DOY | ~0.0749 | ~0.0729 |
| clustered | ~0.0768 | ~0.0746 |

Дополнительный same-year/date prior (источник по другим AOI на той же дате)
дал ещё один устойчивый выигрыш: полный six-year private-like CV — `0.0706`
RMSE. Это особенно логично для кластерных контрольных дат.
На независимых random/clustered масках выигрыш сохранился: `0.07145 → 0.06860`
и `0.07456 → 0.07154` соответственно.

Гармонический/AOI-history fallback оставлен только для патологических
edge-случаев; его вес не увеличивать без отдельного time-block CV.
