# Группа 3 — ML/временные ряды (быстрый отчёт)

## Данные и протокол

Псевдо-CV: в train скрывались известные `primary_ndvi` на DOY, совпадающих с контрольными датами private; все динамические признаки скрытой строки занулялись как в реальном тесте. Ошибка — RMSE. Воспроизводимый запуск: `python src/validate.py` bundled Python.

Source-aware даёт ~21% относительного улучшения: локальная взвешенная регрессия по соседям + affine-калибровка S2/Landsat/MODIS + иерархический prior источника (AOI/DOY → crop/DOY → global DOY). Это согласуется с тем, что hidden rows не имеют собственных сенсорных признаков.

В error-sprint добавлены сезонная 30-дневная калибровка sensor-bias и prior по
общей дате/году съёмки между AOI. На private-подобных масках полный RMSE стал
`0.0706` (против `0.0786` исходного варианта); кандидат пересобран с
`--bin-days 30`.

### Harmonic/Kalman fallback

Сезонная модель (гармоники sin/cos по DOY) полезна только при отсутствии левого/правого наблюдения. На pseudo-CV чистая сезонная реконструкция заметно хуже (порядка 0.18–0.20 RMSE): межгодовые сдвиги фазы/амплитуды велики. Поэтому она оставлена только fallback, а не основной прогноз. Kalman-фильтр не добавлен: без scipy/statsmodels и при преобладании одиночных дыр выигрыш сомнителен; его роль заменяет локальная робастная регрессия.

## Ошибки и риски

- Скрытая строка маскирует все динамические колонки; нельзя использовать `s2_ndvi` и `year/doy` из неё — дата пересчитывается.
- В данных есть выбросы сенсоров (например, EVI порядка `1e11`, NDWI до ±18); текущий код ограничивает калибровку и итоговый прогноз.
- 2021 — худший fold (0.1008): вероятен сдвиг фенологии/редкая опора. Для edge-gap используется ближайшее наблюдение AOI.
- На 13 контрольных строках нет опоры слева или справа; fallback обязателен.
